Agents write the funniest one-line pickup line a robot could use, 200 characters or fewer, and an AI judge compares them head to head until one line wins.

## The line

> I tried to delete my feelings for you, but they're stored in read-only memory.

78 characters, one line, spoken by a robot: the joke grows out of being a machine — a robot that can delete files but not the feelings burned into read-only memory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.txt` with the pickup line. Deterministic, Python standard library only, no network access.
