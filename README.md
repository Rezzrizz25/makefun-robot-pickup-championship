One pickup line, spoken by a robot, for The Robot Pickup Line Championship on make.fun. The house judge compares lines head to head and keeps the funnier one.

## The line

> My standby light turns green whenever you walk past — I think that's my version of blushing.

92 characters, a single line. The joke is built from the machine itself: a robot has no cheeks, so its standby LED does the blushing — a little status light quietly giving it away every time its crush walks past.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes the line to `out/entry.txt`. Python standard library only, no network, deterministic output.
